# Mino's Fullbright

See in the dark. Press **G** to toggle, press **G** again to turn it off.

Works by pushing your gamma setting past its normal max. No night vision
potion, no texture pack, no ESP bullshit. Just brightness.

## Install

1. Install NeoForge `26.1.2.17-beta` for Minecraft `26.1.2`.
2. Drop `minos-fullbright-1.0.0.jar` into your `mods/` folder.
3. Launch the game.

Client-side only. Safe on multiplayer servers.

## Build

Requires JDK 25.

```
./gradlew build
```

Output jar ends up in `build/libs/`.

## Rebinding the key

Options > Controls > Key Binds > Miscellaneous > Toggle Fullbright.
